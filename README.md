
# 🍽️ DishRank

### AI-Powered Restaurant Dish Discovery Platform

DishRank is an AI-powered platform designed to help users discover, explore, and compare restaurant dishes based on ratings, reviews, preferences, and other relevant factors.

## 🚀 Project Overview

The goal of DishRank is to make restaurant dish discovery easier by providing intelligent recommendations and dish rankings.

## 🛠️ Tech Stack

- **Frontend:** React.js, Vite
- **Backend:** Python, FastAPI
- **Database:** PostgreSQL
- **Version Control:** Git & GitHub
- **Machine Learning:** Python (planned)

## ▶️ Running the Project

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
uvicorn app.main:app --reload
```

Backend documentation: http://127.0.0.1:8000/docs

Frontend: http://localhost:5173/
